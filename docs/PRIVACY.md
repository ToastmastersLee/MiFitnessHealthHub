# 本地隐私约定

- 账号、密码、passToken、cookies、API key 不放在环境示例、源码、脚本参数或聊天中。Hub 根本不处理真实认证。
- 桥接器的交互式 setup 由用户自行在本机运行；不要截取输入或把凭证发给 Codex。
- `.gitignore` 忽略 data/、work/、private/、exports/、backups/、.env、数据库和常见日志；不能防止强制添加，也不能发现任意位置的真实 JSON。真实文件必须放到上述私有目录。
- SQLite 为明文本地数据库，没有实现静态加密；Windows 使用所在目录继承的 ACL，本项目不宣称已强化 ACL。先由用户检查共享账户、同步盘、备份及磁盘保护范围。
- Hub 从顶层记录移除 `user_id`；用数据库内随机盐计算 HMAC，防止同一别名混入另一账号。HMAC 和删字段不能替代匿名化，原始 ID、设备字段、位置轨迹、身体指标仍可能识别个人。
- 递归凭证字段检查及不回显输入的错误属于防误用措施；不是任意秘密检测器。只消费可信桥接器导出。
- 默认 CLI 显示条数和日期覆盖，不显示个人测量。即使条数和覆盖日期，也只应在自己认可的工具和上下文中共享。
- 本地 MCP/stdio 与本地 SQLite 不意味着 AI 模型离线。用户授权分析时，提供给 Codex 的汇总或记录会进入当前对话；需要以用户选择的分享范围为准。本项目没有接入个人数据 MCP 或开启遥测。
- `work/logs/bridge-*.log` 是私有诊断，可能含上游账号字段。不能自动读取进对话、提交或上传；用户先自行脱敏。
- 合成测试和 PoC 的数据也存到忽略目录，以便和真实流程保持相同路径纪律。测试源代码中的值全部为编造样本。

发布前至少执行 `git status --short`、`git diff --cached --stat`、`git ls-files` 并检查跟踪列表；不能用 `.gitignore` 代替检查已跟踪内容。

Zepp Life 官方导出不读取 USER 档案；账户范围由官方数字目录名前缀区分，并以带盐 HMAC 存到本地库。
这是防止误混的来源绑定，不是身份认证；不通过重命名目录来合并账号。
Zepp 原始 CSV、SQLite、历史页面、摘要、导入审计和 notebook 均属于私人健康数据，保存在忽略目录。
报告没有外部资源请求，离线打开即可使用；不要把报告网页发布到公开站点。
